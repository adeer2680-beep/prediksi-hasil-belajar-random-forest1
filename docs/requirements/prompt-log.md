### Prompt

> Saya ingin membuat penelitian berbasis web menggunakan Machine Learning dengan topik pendidikan. Berikan beberapa ide judul penelitian yang memiliki fitur intelligent dan dapat menggunakan algoritma klasifikasi.

### Tujuan

Mendapatkan beberapa alternatif topik penelitian yang menggabungkan aplikasi web dan Machine Learning.

### Hasil

Salah satu ide yang dipilih adalah sistem prediksi kategori hasil belajar siswa menggunakan algoritma Random Forest berbasis web.

### Keputusan

Ide tersebut dipilih karena:

- Berkaitan dengan bidang pendidikan.
- Memiliki unsur Machine Learning.
- Dapat dikembangkan menjadi aplikasi web.
- Memiliki output prediksi yang jelas.
